# RevRight (RR)

*RevRight keeps code moving.*

AI is making code cheap. Human review is the bottleneck.

RR is software that eliminates code-review bottlenecks by balancing incentives for engineering teams.

# The product

At a high level, RR matches reviewers to reviews according to expertise.

Rewards fast review with fast review.

You get credit for fast review.
